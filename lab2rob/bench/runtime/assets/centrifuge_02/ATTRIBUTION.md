# Centrifuge_02

Meshes converted from LabUtopia's `Instruments/Centrifuge/Centrifuge_02/Centrifuge_02.usd`
(LabUtopia: High-Fidelity Simulation and Hierarchical Benchmark for Scientific Embodied Agents,
https://rui-li023.github.io/labutopia-site; dataset huggingface.co/datasets/Ruinwalker/LabUtopia-Dataset),
licensed CC BY-NC 4.0 (https://creativecommons.org/licenses/by-nc/4.0/).

Changes: geometry only (materials, textures dropped), converted from centimetres to metres and to
binary STL; the lid is expressed relative to a hinge added for the task. Collision shapes, the hinge
and the latch are new and not part of the original asset.
